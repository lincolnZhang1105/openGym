# 简体中文优先（OEM 1）

上游基线：v1.4.4，`5f5832db56080837b58342ff50f78631dcc63e07`。
功能分支：`feature/oem-chinese-first`。

## 行为

- 新用户、未选择语言的本地模式、缺失或无效语言的配置使用简体中文。
  显式选择的语言继续保留；已配置的服务器 DEFAULT_LANG 仍可覆盖自动默认值。
- 语言菜单将简体中文、繁体中文置于前面，其他语言继续可选。
- 简体/繁体中文动作名称默认不附加英文括号。主动开启英文对照或“仅使用英文名称”
  的设置仍有效。搜索继续同时匹配中文和英文；自定义动作名称保持原样。
- 首次渲染前加载所选语言。异步加载采用最后一次选择，旧请求不能覆盖新语言。
  失败的语言包不会被记成加载成功，重新选择或网络恢复后可以重试；
  英文简介已经加载时，失败的中文简介包也会重试。
- 补充 5,632 个动作的中文简介，以及此前缺失的 4,308 个动作的中文步骤。
  已有 1,324 个动作的步骤及全部中文名称保留。922 个图片变体继续使用原动作 ID 映射。

## 翻译范围和质量记录

源文件是 `catalogue/i18n/zh.json`，生成的 `frontend/src/instr/zh.js` 和
`frontend/src/exercise-desc/zh.js` 不手改。所有文本打包到应用内，运行时无需翻译服务。

新增内容使用公开的上游英文文本辅助翻译；没有发送用户训练资料、密钥或动作媒体。
翻译草稿经过健身术语消歧、定向修订、常见步骤校对和固定抽样检查。
对全部新增句子检查了中英文行对应关系、数字、英文句子残留和已发现的误译词；
修正了翻举、臂屈伸、屈髋、平板支撑、飞鸟、绳索、小腿等错误直译。
这属于辅助翻译及技术校验，**不是专业教练对全部句子的逐条审校**；少数表述仍可能生硬，
后续反馈按动作 ID 修订。未改变上游动作的组数、次数、训练逻辑或原始英文说明。
本次只补齐简体中文，繁体中文说明仍保留上游覆盖范围。

## 同步上游时的接入点

- `frontend/src/oem/locale.js`：默认语言和中文英文对照默认值。
- `default-lang.js`、store、`main.jsx`、`App.jsx`、Settings：启动及设置接入。
- `i18n.js`：加载顺序保护和失败重试，可与上游对应修复合并。
- `i18n-core.js`：语言菜单排序。
- `frontend/index.html`、`web/Dockerfile`：首次语言与对应 CSP hash。
- `catalogue/i18n/zh.json`：按动作 ID 合并上游翻译，不整文件覆盖。
- `frontend/android/app/build.gradle`：OEM versionCode 必须递增，不能随上游版本回退。

上游增加动作后，`chinese-catalogue.test.js` 会指出缺失的中文字段或步骤，补齐后重新生成。
